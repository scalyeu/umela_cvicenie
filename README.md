# umela_cvicenie

Cvičenia z predmetu Umelá inteligencia.

Zadanie 1 je v priečinku dash_iris_Zigo. Je to dashboard nad Iris datasetom
napísaný v Plotly Dash, dáta sa sťahujú až po stlačení tlačidla a filtruje sa
štyrmi slidermi.

Spustenie:

    cd dash_iris_Zigo
    pip install -r requirements.txt
    python app.py

Beží potom na http://127.0.0.1:8050
